# Portfolio assets

Add your personal images to this folder:

- `profile.jpg` — profile portrait used in light mode and as the dark-mode fallback
- `avatar-eyes-closed.png` — optional matching portrait used in dark mode when present
- `access-expert.png` — Microsoft Office Specialist: Access 2019 Expert certificate
- `testdome-html-css.png` — TestDome HTML/CSS certificate
- `enterprise-security.png` — Fundamentals of Enterprise Security certificate
- Project screenshots — optional; replace the CSS-made thumbnail artwork in `../index.html` with your screenshots

The certificate images above are used by the cards in `../index.html`. Project screenshots are still optional placeholders.
